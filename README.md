# Emerald Sound Studio

A VST 3 instrument that replicates Pokémon Emerald's m4a sound engine, on an emulated GBA sound unit. It requires your own Emerald ROM for sound data.

<img width="658" height="448" alt="image" src="https://github.com/user-attachments/assets/79442a45-57d3-44f3-8d75-bb2857559530" />



## Features

- The vanilla m4a driver with ipatix's HQ mixer as an alternative
- Voicegroups are found in the ROM and named by fingerprint, whatever build they come from
- Adjustable PCM voice count and reverb

## Installation

Windows x64, any VST 3 host.

1. Download the latest `EmeraldSoundStudio.vst3` from [Releases](https://github.com/AdAstra-LD/EmeraldSoundStudio/releases).
2. Copy it into `C:\Program Files\Common Files\VST3`.
3. Rescan plug-ins in your DAW and add **Emerald Sound Studio** to an instrument track.
4. Click **Open ROM** and choose your `.gba` file.

No ROM is included. You need your own legally obtained copies.
